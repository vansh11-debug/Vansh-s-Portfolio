Solytics —
Partners Dashboard

Designed a web-based workflow and user management dashboard for a financial analytics firm — clear role-based access, color-coded statuses, and an efficient header-based navigation system.

Dashboard Design Web App Figma B2B

Hi-fi screens — Dashboard, Workflow creation, User management with role-based access

Design Overview & Navigation
User Management Flow
Entry from Dashboard → click "User Management" via top header. Add User button opens a modal to enter user details.
Workflow Navigation
Accessed from the "Workflow" tab in the top navigation header. Users are taken directly to the Workflow Dashboard.
Navigation Structure
Header-based navigation (no sidebar). Key elements — Dashboard, Workflow, Profile — placed top-right for quick access.
Design Decisions
All screens are high-fidelity. Color-coded user statuses (Active, Invited, Suspended) and role differentiation through type styling.
